# AI Study Buddy Backend

This project provides a FastAPI backend for an AI study buddy application, featuring an orchestrator agent, RAG capabilities with ChromaDB, a quiz tool, voice input/output, and a topic tracking memory.

## Tech Stack

- FastAPI
- Groq API (Llama 3.3 70B)
- ChromaDB (vector store)
- PostgreSQL (memory/weak topics)
- OpenAI Whisper (STT)
- gTTS (TTS)

## Setup Instructions

1.  **Clone the repository (if applicable):**

    ```bash
    git clone <repository_url>
    cd studybuddy-backend
    ```

2.  **Environment Variables:**

    Create a `.env` file in the root directory of the project based on `.env.example` and fill in your API keys and database credentials:

    ```
    GROQ_API_KEY=your_groq_api_key
    OPENAI_API_KEY=your_openai_api_key
    DATABASE_URL=postgresql://user:password@db:5432/studybuddy
    CHROMA_DB_PATH=/chroma_data
    ```

3.  **Docker Compose (PostgreSQL and ChromaDB):**

    Start the PostgreSQL and ChromaDB services using Docker Compose:

    ```bash
    docker-compose up -d
    ```

4.  **Install Python Dependencies:**

    ```bash
    pip install -r requirements.txt
    ```

5.  **Run the FastAPI Application:**

    ```bash
    uvicorn main:app --host 0.0.0.0 --port 8000
    ```

    The API will be accessible at `http://localhost:8000`.

## API Endpoint

-   **POST /chat**

    This is the primary endpoint for interacting with the AI study buddy. It accepts user input (text or audio) and returns a response generated by the orchestrator agent, potentially leveraging RAG, quiz generation, or memory tracking.
